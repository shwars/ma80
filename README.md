# Мама — 80

Мобильный статический фотоальбом к 80-летию. Все фотографии расположены по предполагаемому возрасту главной героини; для снимков с EXIF используется год съёмки, для архивных сканов — визуальная оценка.

Сайт не требует сборки или сервера: откройте `index.html` через любой статический HTTP-сервер или включите GitHub Pages для корня ветки.

## Обновление фотографий

```powershell
python -m pip install -r requirements-dev.txt
python scripts/process_photos.py "D:\pictures\NEW\2026-MA80"
```

Скрипт создаёт для каждого исходника полноразмерный WebP и небольшой preview, удаляет публичные EXIF-метаданные и записывает порядок в `data/photos.js` и `data/photos.json`.

## Локальный просмотр

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`.
